# rosalind_solutions

This is a collection of Python scripts correlating to the Bioinformatics in Python course Homework #2 assignment. This assignment contains problems from Rosalind Solutions. 

## Problems Solved 

### 1. Counting DNA Nucleotides 
* For this problem, I counted each nucleotide in a sequence. 

### 2. Transcribing DNA to RNA 
* For this problem, I transcribed a DNA string into an RNA string through replacing all the 'T' with 'U'. 

### 3. Complementing a Strand of DNA 
* For this problem, I used a given DNA string in order to find the reverse compliment strand. To do this I first found the compliment strand and then took the reverse of this complimentary strand. 

### 4. Computing GC Content 
* For this problem, I found the GC content in a given DNA string. I was given multiple FASTA files and then I found the highest GC-content followed by the percent of the highest GC-content. 

### 5. Counting Point Mutations
* For this problem, I found the Hamming distance given two strings. 

### 6. Translating RNA into Protein 
* For this problem, I created a protein string using an RNA string. 


### 7. Finding a Motif in DNA 
* For this problem, I had to use a DNA string and find the locations and positions of all the different substrings given. 

### 8. Calculating Protein Mass 
* For this problem, I took a protein string annd calculated the total weight of the protein string.  

### 9. Locating Restriction Sites 
* For this problem, I found the position and length of every reverse palindrom in the string having length between 4 and 12. 

### 10. Transitions and Transversions 
* For this problem, I used two given DNA strings to find the transitions/transversion ratio.
